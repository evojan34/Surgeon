## خطة تغطية فصول المرجع (2-Year Roadmap)
1. **المبادئ العامة والعناية الحثيثة:** الصدمة، السوائل، الإنتان الجراحي، والتغذية السريرية.
2. **إصابات الحوادث والإنقاذ:** بروتوكولات ATLS، و *Damage Control Surgery*.
3. **الجهاز الهضمي والكبد والبنكرياس والمرارة (HPB):** الأورام، واليرقان الانسدادي، والتهابات البنكرياس.
4. **الجهاز الهضمي السفلي وجدار البطن:** أورام القولون والمستقيم، والفتوق المعقدة.
